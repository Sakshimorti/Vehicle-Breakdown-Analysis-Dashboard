# 🚗 Vehicle Breakdown Analysis Dashboard

## 📌 Project Name
**Vehicle Breakdown Analysis Dashboard**

---

## 📖 Short Description / Purpose

The **Vehicle Breakdown Analysis Dashboard** is an interactive Power BI dashboard developed to analyze vehicle breakdown patterns using vehicle sensor and operational data.

This dashboard helps in:
- Monitoring vehicle breakdown trends
- Analyzing engine and airflow parameters
- Studying road condition impact
- Tracking vehicle speed and RPM behavior
- Identifying factors affecting breakdowns

The project provides meaningful insights for predictive maintenance and vehicle performance analysis.

---

## 🛠️ Tech Stack

The following tools and technologies were used in this project:

- **Power BI** → Dashboard creation and visualization
- **Python** → Data preprocessing and analysis
- **Pandas & NumPy** → Data handling
- **Microsoft Excel / CSV** → Dataset storage
- **Power Query** → Data cleaning and transformation
- **DAX (Data Analysis Expressions)** → KPI calculations
- **ChatGPT (AI Tool)** → Documentation and project assistance

---

## 📂 Data Source

The dataset used in this project contains vehicle operational and sensor-related data for analytical and educational purposes.

The dataset includes:
- Vehicle Speed
- Engine RPM
- Air Temperature
- Engine Coolant Temperature
- AirFlow Rate
- Acceleration Pedal Position
- Road Condition
- Origin and Destination
- Breakdown Status
- Timestamp Data

---

## ✨ Features / Highlights

### 📌 Business Problem

Vehicle breakdowns can lead to operational delays, maintenance costs, and safety risks.  
Manual monitoring of sensor data makes it difficult to identify patterns and root causes of failures.

This dashboard helps analyze vehicle performance metrics and breakdown behavior using interactive visual analytics.

---

### 🎯 Goal of the Dashboard

The dashboard aims to:
- Monitor vehicle breakdown occurrences
- Analyze sensor readings affecting breakdowns
- Study road condition impact on vehicle performance
- Track speed and engine RPM trends
- Identify high-risk operating conditions
- Support predictive maintenance analysis

---

### 📊 Walkthrough of Key Visuals

#### 🔹 Breakdown Trend Analysis
Displays:
- Breakdown count over time
- Timestamp-based breakdown analysis
- Breakdown trend visualization

#### 🔹 Decomposition Tree
Provides:
- Root cause exploration
- Breakdown analysis by:
  - Origin
  - Road Condition
  - Destination

#### 🔹 Vehicle Performance Analysis
Shows:
- Vehicle speed distribution
- Engine RPM analysis
- AirFlow Rate analysis
- Engine Coolant Temperature trends

#### 🔹 Road Condition Analysis
Visualizes:
- Breakdown by road condition
- Average acceleration pedal position
- Vehicle behavior under different conditions

#### 🔹 Sensor-Based Insights
Tracks:
- Air temperature changes
- Airflow rate vs vehicle speed
- Coolant temperature impact

---

### 📈 Business Impact & Insights

- Helps identify factors causing vehicle breakdowns
- Supports predictive maintenance strategies
- Improves vehicle monitoring efficiency
- Reduces maintenance and operational costs
- Enhances safety through early issue detection
- Enables data-driven decision-making
